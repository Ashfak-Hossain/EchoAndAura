# Support

This repository holds the code for [echoandaura.com](https://echoandaura.com).
Where to go depends on what you need.

- **A problem with a ticket, an order or a payment?** Contact the organizer at
  [echoandaura.com/contact](https://echoandaura.com/contact). This repository
  can't see orders, and an issue here won't reach the people who can help.
- **A bug or an idea for the code?** Open an issue from one of the
  [templates](https://github.com/Ashfak-Hossain/EchoAndAura/issues/new/choose).
  Say what you saw, what you expected, and how to repeat it.
- **A question about how the code works?** Open an issue too. The
  [docs](docs/README.md) may answer it first.
- **A security problem?** Report it privately, never in a public issue.
  [SECURITY.md](SECURITY.md) says how.

Pull requests from outside the maintainers are closed without review;
[CONTRIBUTING.md](CONTRIBUTING.md) says why. Everyone taking part here follows
the [Code of Conduct](CODE_OF_CONDUCT.md).
